# ZeichnenBild

Ein Visual-Studio-Projekt zur Einführung in das Zeichnen und Darstellen von Bildern innerhalb einer grafischen Benutzeroberfläche.

## Beschreibung

Das Projekt **ZeichnenBild** beschäftigt sich mit den Grundlagen der grafischen Bilddarstellung. Im Mittelpunkt stehen das Laden, Zeichnen und Positionieren von Bildern sowie die Verwendung grafischer Zeichenfunktionen innerhalb einer Anwendung.

## Funktionen

- Laden und Darstellen von Bildern
- Zeichnen von Bildern auf einer grafischen Oberfläche
- Positionierung von Bildern innerhalb einer Zeichenfläche
- Anpassung der Bildgrösse und Darstellung
- Grundlagen der zweidimensionalen Grafikprogrammierung

## Technologien

- Microsoft Visual Studio
- .NET
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/ZeichnenBild.git
   ```

2. Die Datei `ZeichnenBild.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
